# Submission and demo checklist

The live schedule lists **Sunday, November 15 at 9:00 AM Pacific** as the submission deadline. Confirm the final deliverables in Discord #announcements and Devpost before submitting.

## During the build

- [ ] Submit the team form before equipment checkout.
- [ ] Keep the project runnable on the target hardware.
- [ ] Record dependencies, versions, setup steps, and required permissions.
- [ ] Save source and original or licensed assets; record credits.
- [ ] Keep team-developed code compatible with the required MIT License.
- [ ] Check that hardware and software are sponsor provided or publicly available if entering a track other than Wild West.
- [ ] Capture screenshots and a short fallback demo video once the core interaction works.
- [ ] Test the demo from a clean launch and with weak or no network access.

## Before Sunday 9 AM

- [ ] Recheck official submission requirements and track eligibility.
- [ ] Select no more than two main tracks; enter any eligible sponsored tracks.
- [ ] Make the Git repository public and include the MIT License for team-developed code.
- [ ] Record a vertical short-style demo video no longer than 30 seconds.
- [ ] Complete the team Devpost project page with the demo video and public Git repository.
- [ ] Verify the submitted build, links, credits, and team members.
- [ ] Submit well before 9 AM; organizers download entries exactly then, and missing entries get no judging table.

## Sunday demo

- [ ] Be ready for judging in the Huang basement from 10 AM to noon.
- [ ] Prepare a concise pitch, live interaction, and fallback recording.
- [ ] Return loaner equipment in the Huang basement from noon to 1 PM.
